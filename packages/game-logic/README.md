# @carromverse/game-logic

CarromVerse Core Rules and Turn Engine package. Independent of rendering and UI layers.

## Modules
- `rules/`: Game mode rulesets (Two-player standard, Three-player points, Four-player FFA, Four-player team 2v2)
- `turns/`: Turn management and turn progression
- `scoring/`: Score accumulation, Queen cover values, and due settlement
- `penalties/`: Foul detection, penalty coins, and dues management
- `state/`: Deterministic Carrom State Machine
