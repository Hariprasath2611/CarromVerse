# @carromverse/shared-utils

General utilities, helpers, math functions, and formatters for CarromVerse.

## Modules
- `math/`: 2D vector operations, distances, angles, clamping, physics helpers
- `validation/`: Email, password, username, configuration validators
- `formatting/`: Duration and time formatters (mm:ss)
- `id.ts`: Nanoid / UUID generators for sessions, players, matches
- `events.ts`: Cross-layer event emitter and bridge helpers
