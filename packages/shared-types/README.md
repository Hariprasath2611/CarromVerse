# @carromverse/shared-types

Centralized TypeScript interfaces, types, and enums shared across Frontend, Backend, Game Engine, Game Logic, and Database layers.

## Core Domain Types
- `player.ts`: Player profiles, seats, teams, and statuses
- `game-mode.ts`: Supported game modes, variants, and configurations
- `coin.ts`: Coin types, states, positions, and coordinates
- `striker.ts`: Striker mechanics, bounds, and velocities
- `turn.ts`: Turn lifecycle, history, and actions
- `score.ts`: Score tracking, Queen cover rules, and point breakdowns
- `game-result.ts`: Match outcomes, winner determinations, and stats
- `events.ts`: Cross-layer bridge events (Phaser <-> React Native / Backend)
